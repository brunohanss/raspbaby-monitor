# Contribute

Read `docs/implementation-plan.md` and the ADRs before changing architecture.
Keep changes small. State the backlog ID, scope, tests, and remaining limits.
Use clear technical English for instructions and acceptance criteria.

Run the commands in `docs/development.md` before submitting a change. Include
the native media build when changing GStreamer code. Do not report hardware or
WebView checks as passed without running them. Do not commit media or secrets.
