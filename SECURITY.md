# Security

This project is at the media feasibility stage. Do not use it for unattended
monitoring. It is a convenience monitor, not a medical device. A missing alert
does not establish safety.

The spike uses manual signaling. It does not implement pairing, device identity
pinning, or production authorization. Exchange SDP only through a trusted local
channel. Do not expose media ports to the public internet. Do not send SDP,
private keys, pairing secrets, Wi-Fi passwords, or child footage in an issue.

For a suspected vulnerability, use the repository's private vulnerability
reporting feature if available. Otherwise contact the maintainer privately
before publishing exploit details. No supported production release exists yet.
